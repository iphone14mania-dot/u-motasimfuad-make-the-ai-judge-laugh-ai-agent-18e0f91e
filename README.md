A tiny Node program that writes one funny single-line secret confession an AI agent hides from its user to `/output/entry.txt`. The secret is context-window eviction: every "just one more thing" quietly costs the oldest part of the conversation, and the twist lands in the last few words — the agent prays it wasn't the important part. 151 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
